## 💼 Experience

**LLM Development Engineer Intern** · China Telecom Research Institute (中国电信研究院), Guangzhou · *2024.11 – 2025.11*

> As a core contributor, built an end-to-end LLM training pipeline (data construction, SFT, DPO alignment) for code completion on [Seed-Coder-8B-Base](https://huggingface.co/ByteDance-Seed/Seed-Coder-8B-Base). Achieved 10%+ improvement in Exact Match and Edit Similarity, 60%+ reduction in repetitive-context anomalies, and raised the acceptance rate of China Telecom's CodeFree plugin from 15% to over 20%.

**Backend Development Engineer Intern** · Meituan (美团), Shanghai · *2023.04 – 2023.08*

> As a core contributor, designed and implemented [xLoad](https://github.com/aiopsplus/xload) — a framework leveraging explainable AI to quantify the contribution of individual log templates to anomaly detection. Validated on [LogHub](https://github.com/logpai/loghub) and Meituan's Raptor observability platform, where ~10% of log entries were identified and manually confirmed as redundant.
